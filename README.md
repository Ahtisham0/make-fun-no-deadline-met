# One Line, No Deadline Met

An entry for the make.fun bounty
[u-markk-st-one-line-no-deadline-met-6adc00ce](https://make.fun/c/u-markk-st-one-line-no-deadline-met-6adc00ce).

## What it does

`main.ts` writes a single original one-line joke excusing a missed
deadline to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`)
and prints it:

> I missed the deadline because I spent all week writing the perfect excuse for missing the deadline.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs as-is). The output file
holds exactly that one line — 1–200 characters, no second line, no link,
no picture.
